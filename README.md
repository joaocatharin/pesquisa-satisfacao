# 📊 Pesquisa de Satisfação - TudoWeb

Programa em Python desenvolvido para coletar e analisar a opinião de clientes sobre o atendimento prestado pela empresa **TudoWeb**.

---

## 📋 Descrição do Projeto

Este projeto realiza uma pesquisa de opinião com **50 entrevistados**, coletando as seguintes informações:

- Nome do entrevistado
- Idade
- Opinião sobre o atendimento:
  - `1` → EXCELENTE
  - `2` → BOM
  - `3` → RUIM

Ao final da pesquisa, o programa exibe:
- Quantidade de respostas **EXCELENTE**
- Quantidade de respostas **RUIM**

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- Estruturas de repetição (`for` e `while`)
- Estruturas de decisão (`if`, `elif`, `else`)
- Entrada e saída de dados (`input` e `print`)

---

## ▶️ Como Executar

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo `pesquisa_satisfacao.py`.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python pesquisa_satisfacao.py
```
